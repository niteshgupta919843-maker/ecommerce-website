Nitesh Shoes – E-Commerce Website

Nitesh Shoes is a simple and stylish front-end e-commerce website created using HTML, CSS, and JavaScript.
This project includes a clean UI, product cards, a working search bar, and a beginner-friendly layout.

🚀 Features

Clean and modern homepage

Product cards with image, name & price

Search bar to filter products

Responsive design

Smooth UI with colors & shadows

Simple and organized file structure

🛠️ Tech Stack

HTML5 – Structure

CSS3 – Styling

JavaScript – Functionality
